# Verilog Testbench Practice

A repository dedicated to learning digital circuit
verification using Verilog HDL.

## Learning Objectives

- Understand simulation methodology
- Develop Verilog testbenches
- Generate clock and reset signals
- Apply test vectors
- Analyse simulation waveforms
- Identify functional design errors
